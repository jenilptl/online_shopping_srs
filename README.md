# Online Shopping System - Software Engineering Project

This repository contains the Software Requirement Specification (SRS) and related UML diagrams for the **Online Shopping System** project, developed for the Semester 4 Software Engineering lab.

## Project Overview
The Online Shopping System is a web-based application that allows customers to browse products, add them to a basket, and make purchases online. It includes features for user authentication, product management, and order processing.

## Contents
- **[SRS_Online_Shopping_System.docx](SRS_Online_Shopping_System.docx)**: The primary Software Requirement Specification document.
- **[srs_diagrams/](srs_diagrams/)**: A collection of UML diagrams and screenshots used in the project.
  - Activity Diagrams (Buyer, Flow)
  - DFD (Data Flow Diagrams) Level 0 and Level 1
  - Class Diagrams
  - Sequence Diagrams
  - State Diagrams
  - UI Screenshots (Login, Dashboard, Product Detail, Cart, Profile)
- **[notes/](notes/)**: Lecture slides, project definitions, and other study materials.
- **[personal/](personal/)**: Personal documents (e.g., resumes).

## Key Diagrams
- **DFD Level 1**: Outlines the functional breakdown of the system processes.
- **Swimlane/Activity Diagram**: Shows the flow of actions between different actors (Customer, Admin, System).
- **State Diagram**: Illustrates the lifecycle of products or orders within the system.
